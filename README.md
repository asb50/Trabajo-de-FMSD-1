# Trabajo FMSD 1 - Consulta y Análisis de Datos de AEMET

Proyecto de la asignatura **Fundamentos Matemáticos de los Sistemas de Datos** enfocado en la integración con la API de [AEMET OpenData](https://opendata.aemet.es/) para la extracción, procesamiento y análisis de datos meteorológicos.

## Descripción y Objetivos
- Extracción de series temporales de temperaturas, precipitaciones, etc.
- Limpieza, estructuración y análisis estadístico de los datos.
- Generación de visualizaciones para la interpretación de resultados.

## Requisitos Previos
* Python 3.9 o superior
* Una API Key válida de [AEMET OpenData](https://opendata.aemet.es/centrodedescargas/inicio)
